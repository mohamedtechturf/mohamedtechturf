## 👨‍💻 About Me

I am a Systems & Systems Tools Engineer with a deep passion for networking, OS architecture, and low-level programming. I actively explore the intersection of high performance and elegant design.

- 🔭 **Currently building:**
<br>1- **L++**, a custom systems programming language leveraging LLVM with an assisted memory ownership model and compile-time CSS visual styling.
<br>2- **Bluepreter**, A successor to Netpreter, A bluetooth auditing framework written mainly in C, featuring a unified CLI and a web-based UI.
<br>3- **Aerocord**, Custom made discord client made for very low resources usage and it captures the aesthetics of old MSN.
- ⚡ **Developing:** **Netpreter v3.0**, a zero-dependency network auditing and scanning framework with SQLite database persistence and a local browser dashboard.
- 🐧 **Tinkering:** Actively exploring different OS distributions and studying them, flashing custom OS firmware for various devices such as mobile devices. 
- 🎨 **Aesthetics:** I am a big fan of the Frutiger Aero and nightcore design aesthetic and integrate custom UI concepts using Photoshop.
